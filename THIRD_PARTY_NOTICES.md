# Third-Party Open-Source References

BigChange Keyboard Game is a classroom-focused typing tutor. The projects below were reviewed for architecture, interaction patterns, and teaching ideas.

## KeyQuest
- Repository: https://github.com/ovurevu/keyquest
- License: MIT
- Role: original project base and early typing/game inspiration.

## Typing Practice
- Repository: https://github.com/jgzuo/typing-game
- License: MIT
- Role: reference for simple browser typing, timers, and local history.

## Layer Tutor
- Repository: https://github.com/thebiglaskowski/layer-tutor
- License: MIT
- Role: reference for separating typing logic, UI, storage, and automated tests.

## Monkeytype
- Repository: https://github.com/monkeytypegame/monkeytype
- License: GPL-3.0
- Role: architecture/behavior reference for word-scoped typing, real input handling, event logging, timed tests, and immediate feedback.
- BigChange does not copy Monkeytype source into V3.

## Qwerty Learner
- Repository: https://github.com/RealKai42/qwerty-learner
- License: GPL-3.0
- Role: teaching/reference model for chapters, word repetition, mistake tracking, review, dictation, and weak-item practice.
- BigChange does not copy Qwerty Learner source into V3.

## Open-Typer
- Repository: https://github.com/Open-Typer/Open-Typer
- License: GPL-3.0
- Role: reference for keyboard-layout-aware and generated lesson concepts.
- BigChange does not copy Open-Typer source into V3.

## Tux Typing
- Website: https://tuxtyping.org/
- Role: reference for kid-friendly lesson/game progression.

BigChange-specific curriculum, branding, classroom flow, JavaScript implementation, tests, progress model, and games remain maintained in this repository.
