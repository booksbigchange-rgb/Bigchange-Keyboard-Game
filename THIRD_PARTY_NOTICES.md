# Third-Party Open-Source References

BigChange Keyboard Game is developed as a classroom-focused typing tutor. The project has studied and adapted architecture and interaction ideas from the following MIT-licensed open-source projects:

## KeyQuest
- Repository: https://github.com/ovurevu/keyquest
- License: MIT
- Use in BigChange: original project base, classroom typing-tutor concepts, lesson/progress/game inspiration.

## Typing Practice
- Repository: https://github.com/jgzuo/typing-game
- License: MIT
- Use in BigChange: reference for a simple real-browser-input typing interaction, live statistics, timers, and local history.

## Layer Tutor
- Repository: https://github.com/thebiglaskowski/layer-tutor
- License: MIT
- Use in BigChange: reference for separating pure typing logic from UI/storage, progressive lesson architecture, and automated testing.

BigChange-specific curriculum, branding, classroom flow, UI, progress model, tests, and game integration are maintained in this repository.
